```go
package config

// Action types
const (
    ActionCopy    = "copy"
    ActionSymlink = "symlink"
    ActionRun     = "run"
)

// Action represents a single config action
type Action struct {
    Type string // "copy", "symlink", or "run"
    Path string // file/directory path or command string for "run"
    Line int    // source line number (for error reporting)
}
```

Create `internal/config/parser.go`:
- `func ParseFile(path string) ([]Action, error)` — open file, scan line-by-line with bufio.Scanner
- Use `strings.TrimSpace()` on each line
- Skip blank lines and lines starting with `#`
- Use `strings.SplitN(line, " ", 2)` to split into action type and path (critical: SplitN not Split, so `run npm install --save` keeps command intact)
- `strings.TrimSpace()` on the path portion after splitting
- Track line numbers for error reporting
- Check `scanner.Err()` after loop (critical: catches I/O errors)
- Return error with line number for lines that don't contain a space separator

Run `go test ./internal/config/ -run TestParse -v` — all tests must pass.

GREEN — Create `internal/config/resolve.go`:
- `func ResolveConfigPath(repoRoot string, name string) (string, error)`
- If `name == ""`: path = `filepath.Join(repoRoot, ".wtconfig")`
- Else if `strings.Contains(name, "/")`: path = name (exact path)
- Else: path = `filepath.Join(repoRoot, ".wtconfig-"+name)`
- Check `os.Stat(path)` — if error: return `fmt.Errorf("config file not found: %s", path)`
- Return path, nil

GREEN — Create `internal/config/flags.go`:
- `func BuildActionsFromFlags(copyPaths, symlinkPaths, runCommands []string) []Action`
  - Build actions in order: iterate copyPaths appending ActionCopy, then symlinkPaths appending ActionSymlink, then runCommands appending ActionRun
  - NOTE on ordering: Cobra collects each flag type into its own slice. Within each type, order matches CLI order. But the interleaved order across types is NOT preserved by Cobra's StringSliceVar. The user decision says "sequential in flag order as given on command line." Since Cobra cannot preserve interleaved order, document this limitation and use type-grouped order (all copies, then all symlinks, then all runs). This is the best Cobra can do.
  - Line numbers set to 0 (not from file)

- `func CheckDuplicatePaths(copyPaths, symlinkPaths []string) error`
  - Use map[string]string to track path -> action type
  - Check copyPaths first, then symlinkPaths
  - If duplicate found: return error with path and conflicting action types
  - Run commands are NOT checked for duplicates (they're commands, not file paths)
