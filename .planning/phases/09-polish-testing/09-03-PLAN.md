Create `tests/shell/shell_test.go` with Go test functions that:

**Prerequisites check:** Each test function checks if the target shell is available (`exec.LookPath("bash")`, etc.). If not found, `t.Skip("bash not available")`. This allows tests to pass on systems without all shells.

**Shell version tier (Claude's discretion):**
- bash: must-pass (skip only if bash not installed at all)
- zsh: must-pass (skip only if zsh not installed)
- fish: best-effort (skip if not installed -- fish is less common in CI)

**Test pattern for each shell (bash example):**

```go
func TestBashWrapperGoto(t *testing.T) {
    bashPath, err := exec.LookPath("bash")
    if err != nil {
        t.Skip("bash not available")
    }

    // Build wt binary to a temp location
    tmpBin := buildWtBinary(t)

    // Create git fixtures
    tmpDir := t.TempDir()
    runSetup(t, tmpDir)

    // Write a test script that:
    // 1. Sets PATH to include tmpBin directory
    // 2. Sources the bash wrapper
    // 3. cd's into the main worktree
    // 4. Runs 'wt goto feature'
    // 5. Prints $PWD
    script := fmt.Sprintf(`
        export PATH="%s:$PATH"
        source "%s"
        cd "%s/repo.git/main"
        wt goto feature
        echo "RESULT_PWD=$PWD"
    `, filepath.Dir(tmpBin), wrapperPath("bash"), tmpDir)

    cmd := exec.Command(bashPath, "-c", script)
    output, err := cmd.CombinedOutput()
    // Parse RESULT_PWD from output
    // Assert it ends with /feature
}
```

**Helper functions:**
- `buildWtBinary(t *testing.T) string` -- runs `go build -o <tmpdir>/wt ./` from project root, returns path to binary. Use `t.Helper()`.
- `runSetup(t *testing.T, dir string)` -- runs the setup.sh script
- `wrapperPath(shell string) string` -- returns absolute path to `internal/shell/templates/wrapper.<shell>`

**Test cases (3 per shell, same logic):**
1. `TestXxxWrapperGoto` -- source wrapper, cd to main worktree, run `wt goto feature`, verify PWD changed to feature worktree
2. `TestXxxWrapperHome` -- source wrapper, cd to feature worktree, run `wt home`, verify PWD changed to main worktree
3. `TestXxxWrapperNew` -- source wrapper, cd to main worktree, run `wt new test-branch`, verify PWD changed to new worktree

For fish, the script syntax differs:
```fish
set -x PATH "{tmpBin}" $PATH
source "{wrapperPath}"
cd "{tmpDir}/repo.git/main"
wt goto feature
echo "RESULT_PWD=$PWD"
```

Use `exec.Command(fishPath, "-c", script)` for fish.

**Important:** The wt binary must be built ONCE per test run, not per test. Use `TestMain` or a `sync.Once` to build it once and share across tests.

**Build tags:** No special build tags needed. These tests run with `go test ./tests/shell/...`.

Mark slow: add `if testing.Short() { t.Skip("skipping shell e2e test in short mode") }` at the top of each test so `go test -short` skips them.
