**Structure (in order):**

1. **Header and tagline**
   - `# wt`

2. **Features** (bullet list, concise)
   - Create and navigate worktrees with short commands
   - Auto-configure new worktrees with .wtconfig (copy/symlink files)
   - Eject branches into dedicated worktrees with stash handling
   - Tab completion for worktree names in all shells
   - Works with both regular and bare git repos

3. **Installation**
   - Primary method: `npm install -g @potato/wt` then `wt install`
   - One-liner: `npx @potato/wt install` (for try-before-commit)
   - What `wt install` does: detects shell, adds shell wrapper to rc file, sets up completions
   - Requirements: Node.js 16+, git 2.5+ (worktree support)
   - Uninstall: `wt uninstall && npm uninstall -g @potato/wt`

4. **Quick Start** (5-step walkthrough with explanations)
   ```
   wt init                    # Set up .wtconfig in your repo
   wt new feature-auth        # Create worktree + branch
   wt goto feature-auth       # Jump to it
   wt home                    # Go back to main
   wt delete feature-auth     # Clean up
   ```
   Brief explanation after each command.

5. **Commands** (one subsection per command)
   For each command:
   - Usage line

   Commands in order: init, new, goto, home, eject, list, merge, rebase, delete

   Skip install/uninstall/shell-init/completion/version in command reference -- these are covered elsewhere or are plumbing.

6. **Configuration (.wtconfig)**

   - copy vs symlink: when to use each, with examples

   - Full example .wtconfig for a Node.js project

7. **Shell Support**
   - Supported shells: bash (3.2+), zsh (5.8+), fish (3.0+)
   - How it works: thin shell wrapper handles cd, binary does everything else
   - Tab completion: automatic for goto, delete, merge, rebase
