  <files>internal/ui/errors.go, cmd/root.go</files>
  <action>
Create `internal/ui/errors.go` with:

1. **Color support** using the `fatih/color` library (already in go.mod). fatih/color auto-detects TTY and respects NO_COLOR env var out of the box -- no manual detection needed.

2. **FormatError(err error, cmd string) string** function:
   - Prints error in red: `Error: <message>`
   - Appends help footer: `Run 'wt help <cmd>' for details`
   - The `cmd` parameter is the subcommand name (e.g., "goto", "delete")
   - When cmd is empty, omit the footer (for internal errors that aren't command-specific)

3. **Warn(msg string)** function:
   - Prints warning in yellow to stderr: `Warning: <message>`

Update `cmd/root.go` Execute() function:
- Replace `fmt.Fprintf(os.Stderr, "error: %s\n", err)` with the new FormatError
- Extract the subcommand name from the command tree to pass to FormatError. Use `rootCmd.CalledAs()` or parse from args. Cobra's `cmd.Name()` on the matched command gives the subcommand name. Since Execute() only gets the error, use a package-level variable or extract from os.Args.
- Simple approach: parse os.Args[1] as the command name if it exists, otherwise empty string.

Do NOT modify individual cmd/*.go files. All error formatting happens centrally in Execute().
