  <name>Task 1: Create build and publish automation scripts</name>
  <files>
    scripts/build-npm.sh
    scripts/publish-npm.sh
  </files>
  <action>
    **1. Create `scripts/build-npm.sh`:**

    This script:
    a. Runs `goreleaser build --snapshot --clean` to cross-compile for all 4 platforms
    b. Maps goreleaser output filenames to npm platform directories:
       - `dist/wt_darwin_arm64/wt` -> `npm/platforms/darwin-arm64/bin/wt`
       - `dist/wt_darwin_amd64_v1/wt` -> `npm/platforms/darwin-amd64/bin/wt`
       - `dist/wt_linux_arm64/wt` -> `npm/platforms/linux-arm64/bin/wt`
       - `dist/wt_linux_amd64_v1/wt` -> `npm/platforms/linux-amd64/bin/wt`
       NOTE: goreleaser uses `_v1` suffix for amd64 builds (GOAMD64 default level).
       Verify actual dist/ output paths after first build and adjust if needed.
    c. Applies `chmod +x` to all staged binaries (Pitfall 1 from research)
    d. Prints summary of what was staged

    Use `set -euo pipefail` for safety. Accept optional `--snapshot` flag (default behavior).
    The script should be idempotent -- safe to run multiple times.

    **2. Create `scripts/publish-npm.sh`:**

    This script:
    a. Takes VERSION as first argument (required, e.g., "2.0.0")
    b. Updates version in ALL 5 package.json files (main + 4 platforms)
    c. Updates optionalDependencies versions in main package.json to match
    d. Publishes platform packages FIRST (all 4), then main package
    e. Uses `npm publish --access public` (Pitfall 2 from research -- scoped packages default to private)
    f. Supports `--dry-run` flag that uses `npm publish --dry-run` instead

    Use `set -euo pipefail`. For version updates, use `node -e` with JSON.parse/stringify (jq may not be installed). Print progress for each package.

    Make both scripts executable: `chmod +x scripts/*.sh`
  </action>
  <verify>
    - `bash -n scripts/build-npm.sh` passes (valid bash syntax)
    - `bash -n scripts/publish-npm.sh` passes (valid bash syntax)
    - `ls -la scripts/` shows both files are executable
    - `grep 'goreleaser build' scripts/build-npm.sh` confirms goreleaser usage
    - `grep 'npm publish --access public' scripts/publish-npm.sh` confirms public access flag
  </verify>
  <done>
    Both automation scripts exist, are executable, and have correct bash syntax. Build script maps goreleaser output to npm platform dirs. Publish script handles coordinated version bumps and ordered publishing (platforms first, main last).
  </done>
