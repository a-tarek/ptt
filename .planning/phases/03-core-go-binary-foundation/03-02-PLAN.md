  <action>
    **1. Create `internal/git/resolve.go` — worktree name resolution (INFRA-03):**

    Port the suffix-matching logic from wt.zsh `_wt_resolve_path()` (lines 448-460):

    - Function `ResolveWorktree(name string) (*Worktree, error)`:
      1. Call `ListWorktrees()` to get all worktrees
      2. For each worktree, extract directory basename from `wt.Path` using `filepath.Base()`
      3. Match if:
         - basename ends with `-<name>` (suffix match: "repo-staging" matches "staging")
         - OR basename equals `<name>` exactly (exact match)
      4. If exactly one match → return that Worktree
      5. If zero matches → return error: `worktree '<name>' not found`
      6. If multiple matches → return error: `worktree '<name>' is ambiguous` (edge case, good hygiene)

    **2. Create `cmd/delete.go` — implement `wt delete` (CMD-09):**

    Per user decisions:
    - No confirmation for clean worktrees — deletes immediately
    - Dirty worktrees prompt for confirmation: "Worktree 'foo' has uncommitted changes. Delete? [y/N]"
    - `--force` skips all confirmation, even for dirty worktrees
    - Branch NOT deleted by default — `--branch` flag to also delete the branch
    - Cannot delete current worktree — error: "can't delete current worktree"
    - Single worktree per invocation (no multi-delete)
    - Silent on success — no output on successful delete

    Implementation:
    - Create `deleteCmd` as cobra.Command with Use: "delete <worktree>", Short: "Remove a worktree", Args: cobra.ExactArgs(1)
    - Add flags:
      - `--force` / `-f` bool: skip confirmation for dirty worktrees
      - `--branch` / `-b` bool: also delete the branch after removing worktree
    - In RunE:
      1. Get worktree name from `args[0]`
      2. Call `git.ResolveWorktree(name)` — if error, return it (name not found)
      3. Call `git.CurrentWorktreeRoot()` — if resolved path equals current, return error "can't delete current worktree"
      4. Check if dirty: call `git.IsDirty(resolved.Path)`
      5. If dirty and not `--force`:
         - Print to stderr: `Worktree '<basename>' has uncommitted changes. Delete? [y/N] `
         - Read user input from stdin
         - If not "y" or "Y", return error (silently exit — user declined)
         - Use `fmt.Fprintf(os.Stderr, ...)` for the prompt (prompt is not data)
         - Read response with `bufio.NewReader(os.Stdin).ReadString('\n')`
      6. Execute `git worktree remove <path>`:
         - If dirty and user confirmed (or --force), use `git worktree remove --force <path>`
         - If clean, use `git worktree remove <path>`
      7. If `--branch` flag:
         - Get branch name from resolved worktree's Branch field
         - Execute `git branch -d <branch>` (safe delete — won't delete unmerged)
         - If branch delete fails (unmerged), try `git branch -D <branch>` only if `--force` was also passed
         - If not `--force` and branch is unmerged, print warning to stderr: `warning: branch '<branch>' not fully merged, use --force to delete`
      8. Return nil (silent success)
    - Register: `rootCmd.AddCommand(deleteCmd)` in init()
