<task type="auto">
  <name>Task 1: Add shared git helper functions</name>
  <files>internal/git/repo.go, internal/git/repo_test.go</files>
  <action>
Create `internal/git/repo.go` with these functions:

1. `IsBareRepository() (bool, error)` — runs `git rev-parse --is-bare-repository`, returns true if "true", false if "false", error on failure.

2. `GetRepoRoot() (string, error)` — returns the root of the repository regardless of worktree position. For bare repos: `git rev-parse --git-dir` (which returns the bare repo root). For regular repos: `git rev-parse --show-toplevel` (the main checkout root). This is the "home" path for both modes.

3. `GetHomePath() (string, error)` — returns the path of the first worktree from `git worktree list --porcelain` (first "worktree " line). This is the bare repo root or the main checkout. Used by `wt home`.

4. `WorktreePath(repoRoot string, name string) (string, error)` — computes the target path for a new worktree:
   - Bare repo (`IsBareRepository()` returns true): nested mode -> `filepath.Join(repoRoot, name)` (e.g., `/code/wt/staging`)
   - Regular repo: sibling mode -> `filepath.Join(filepath.Dir(repoRoot), filepath.Base(repoRoot)+"-"+name)` (e.g., `/code/wt-staging`)
   - The `repoRoot` parameter should be the repo root path from GetHomePath(), NOT the current worktree root. This avoids the v1.0 compounding bug (per CONTEXT.md decision).
   - Returns error if the computed path already exists as a directory.

5. `CurrentBranch() (string, error)` — runs `git branch --show-current`, returns branch name. Returns error if detached HEAD (empty output).

Create `internal/git/repo_test.go` with unit tests for `WorktreePath` only (it's the only function with pure logic). Test cases:
- Bare repo path: `WorktreePath("/code/wt", "staging")` when bare -> `/code/wt/staging`
- Regular repo path: needs filesystem (tmpdir), create the dir, call the function
- Error when target already exists

Note: IsBareRepository, GetHomePath, CurrentBranch are thin wrappers around git commands and will be tested via integration tests with the commands. Do NOT mock git -- these are too thin to warrant mocking.

Follow the existing error handling pattern from worktree.go (check ExitError for stderr).

**cmd/goto.go** — `wt goto <worktree>`:
- Use: `"goto <worktree>"`, Short: `"Switch to a worktree"`, Args: `cobra.ExactArgs(1)`
- Package-level `var outputPath bool` flag, registered as hidden persistent flag on root in this file's `init()` (so all commands can use it). Register with `rootCmd.PersistentFlags().BoolVar(&outputPath, "output-path", false, "output only the target path")` then `rootCmd.PersistentFlags().MarkHidden("output-path")`.
- IMPORTANT: Declare `outputPath` as a package-level var in goto.go. Other command files in the same `cmd` package can access it directly.
- Check `git.IsInsideGitRepo()` first, error "not inside a git repository".
- Call `git.ResolveWorktree(args[0])` for suffix-match resolution.
- Check already-there: compare resolved `wt.Path` with `git.CurrentWorktreeRoot()`. If same, print "Already in {basename}" to stderr, return nil (exit 0).
- Check dirty status: `git.IsDirty(wt.Path)`.
- If `outputPath` is true: print `wt.Path` to stdout (just the path, nothing else via `fmt.Println(wt.Path)`).
- Always print confirmation to stderr: `fmt.Fprintf(os.Stderr, "Switched to %s (branch: %s, %s)\n", basename, wt.Branch, dirtyStr)` where dirtyStr is "dirty" or "clean".
- If `outputPath` is false (direct invocation): also print the confirmation to stdout.

**cmd/home.go** — `wt home`:
- Use: `"home"`, Short: `"Switch to main worktree"`, Args: `cobra.NoArgs`
- Check `git.IsInsideGitRepo()`.
- Get home path via `git.GetHomePath()`.
- Check already-there: compare home path with `git.CurrentWorktreeRoot()`. If same, print "Already home" to stderr, return nil.
- Get basename of home path for display.
- Check dirty status of home path.
- If `outputPath`: print home path to stdout.
- Always print confirmation to stderr with branch and dirty status. For bare repo root (no branch), display "(bare)" instead of branch name.

**cmd/merge.go** — `wt merge <worktree>`:
- Use: `"merge <worktree>"`, Short: `"Merge a worktree's branch into current"`, Args: `cobra.ExactArgs(1)`
- Check `git.IsInsideGitRepo()`.
- Resolve worktree: `git.ResolveWorktree(args[0])`.
- Error if resolved worktree has no branch (bare/detached): "worktree '%s' has no branch".
- Run `git merge <branch>` using `exec.Command`. Pass through stdout and stderr from git to the user (use `cmd.Stdout = os.Stdout; cmd.Stderr = os.Stderr`). Return the exit error if merge fails.
- Print "Merging %s into current branch..." to stderr before running git merge.
- No `--output-path` support needed (no cd involved, per CONTEXT.md discretion).

**cmd/rebase.go** — `wt rebase <worktree>`:
- Identical structure to merge.go but runs `git rebase <branch>`.
- Print "Rebasing onto %s..." to stderr before running.

Register all commands in their respective `init()` functions via `rootCmd.AddCommand(...)`.
