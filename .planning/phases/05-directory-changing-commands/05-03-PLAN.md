  <name>Task 1: Implement wt eject command</name>

  <action>
Create `cmd/eject.go` implementing the `wt eject` command. Port the v1.0 flow from wt.zsh `_wt_eject` faithfully.

**Flags** (same as wt new, registered in `init()`):
- `--config <name>` (string): use `.wtconfig-<name>`
- `--skip-config` (bool): skip file-based config
- `--copy` ([]string): inline copy overrides
- `--symlink` ([]string): inline symlink overrides

**Command definition:**
- Use: `"eject [name]"`, Short: `"Eject current branch into its own worktree"`, Args: `cobra.MaximumNArgs(1)`
- Optional name argument: if not provided, default to current branch name with "/" replaced by "-"

**RunE logic (in order):**

1. **Check git repo**: `git.IsInsideGitRepo()` -> error "not inside a git repository"

2. **Get current state**:
   - `currentBranch` via `git.CurrentBranch()` -> error "detached HEAD -- nothing to eject" if fails
   - `srcRoot` via `git.CurrentWorktreeRoot()` (the current worktree where we are)
   - `homePath` via `git.GetHomePath()` (bare repo root / main worktree)

3. **Determine fallback branch**:
   - If `srcRoot == homePath` (we're in the home worktree):
     - Try main: `git show-ref --verify --quiet refs/heads/main`
     - Try master: `git show-ref --verify --quiet refs/heads/master`
     - If neither exists: error "neither 'main' nor 'master' branch exists"
   - If `srcRoot != homePath` (we're in a non-home worktree):
     - Get directory basename of srcRoot
     - Get basename of homePath (repo name)
     - Strip repo name prefix + "-" from directory basename to get suffix
     - Fallback branch = suffix
     - Verify fallback branch exists: `git show-ref --verify --quiet refs/heads/{fallback}`
     - If not: error "fallback branch '{fallback}' does not exist"
   - Error if `currentBranch == fallbackBranch`: "already on '{fallback}' -- nothing to eject"

4. **Determine worktree name and path**:
   - `name`: from args[0] if provided, else `strings.ReplaceAll(currentBranch, "/", "-")`
   - Call `git.WorktreePath(homePath, name)` for target path

5. **Print start message** to stderr: `"Ejecting branch '%s' into %s"` with branch and target basename

6. **Stash uncommitted changes** (including untracked):
   - Get stash count before: `git stash list | wc -l` (or count lines of `git stash list` output)
   - Run: `git stash push -u -m "wt-eject: {currentBranch}"`
   - Get stash count after
   - `didStash = (countAfter > countBefore)`
   - If stashed: print "Stashed uncommitted changes" to stderr

7. **Switch to fallback branch**:
   - Run: `git checkout {fallbackBranch}`
   - If fails: pop stash back if didStash (`git stash pop`), return error "failed to switch to '{fallback}'"
   - Print "Switched to '{fallback}'" to stderr

8. **Create new worktree**:
   - Run: `git worktree add {targetPath} {currentBranch}`
   - The branch already exists (it's the one we just ejected from), so no `-b` needed
   - If fails: rollback -- `git checkout {currentBranch}`, pop stash if didStash, return error
   - Print "Created worktree: {basename}" to stderr

9. **Pop stash in new worktree**:
   - Only if didStash
   - Run: `git -C {targetPath} stash pop`
   - Check exit code. If non-zero (merge conflicts):
     - Print WARNING to stderr: "Stash restored with conflicts -- resolve before committing"
     - Do NOT fail the command (the stash was still popped, just with conflicts)
   - If stash pop succeeds cleanly: print "Restored uncommitted changes in new worktree" to stderr

10. **Apply config** (same logic as wt new):
    - Same flag hierarchy: --skip-config bypasses file config, --copy/--symlink always apply
    - Source root for config files = srcRoot (the original worktree we were in)
    - Target root = targetPath (the new worktree)
    - Call config.ResolveConfigPath, ParseFile, ValidateActions, BuildActionsFromFlags, setup.ExecuteActions
    - Silently skip if no .wtconfig and no flags
    - On failure: the setup.ExecuteActions already removes the worktree directory via rollback. But we also need to undo the branch switch and stash. So if config fails:
      - `git checkout {currentBranch}` back to original branch in the source worktree
      - Pop stash if didStash
      - Return error
    - On success: print "Applied {configName} ({N} actions)" to stderr

11. **Final confirmation** to stderr:
    - Check dirty status of new worktree
    - Print "Switched to {basename} (branch: {currentBranch}, {clean|dirty})"

12. **Output path**: If `outputPath` flag is true, print just `targetPath` to stdout. If false, also print confirmation to stdout.

**Rollback strategy** (matches v1.0):
Each step has its own rollback if it fails. The general pattern:
- Step 6 fail: nothing to undo
- Step 7 fail: pop stash
- Step 8 fail: checkout back + pop stash
- Step 9 fail: non-fatal warning (don't fail command)
- Step 10 fail: executor removes worktree dir, then checkout back + pop stash

All git commands use `exec.Command` with stderr captured for error messages.
