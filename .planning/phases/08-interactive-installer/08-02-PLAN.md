  <action>
Create `cmd/uninstall.go` — the `wt uninstall` cobra command.

**Command setup:**
- `Use: "uninstall"`, `Short: "Remove wt shell integration"`
- NOT hidden (user-facing)
- `Args: cobra.NoArgs`

**Flow (in RunE):**

Step 1 — Detect shell and rc file:
```
wt uninstall — Remove Shell Integration
========================================

Detecting shell... zsh
RC file: ~/.zshrc
```
- Call `shell.DetectShell()` to get shell type
- Call `installer.RCFilePath(shellType)` to get rc file path
- Read rc file content. If file doesn't exist, print "RC file not found" and exit 0.

Step 2 — Check for existing installation:
- Call `installer.HasMarkerBlock(content)` — if false:
  ```
  wt is not configured in ~/.zshrc
  No changes needed.
  ```
  Exit 0.

Step 3 — Show what will be removed:
```
The following block will be removed from ~/.zshrc:

  # >>> wt >>>
  # Managed by wt installer — do not edit this block manually
  eval "$(wt shell-init)"
  # <<< wt <<<

Proceed? [Y/n]
```
- Use `bufio.NewReader(os.Stdin)` for input
- If decline ("n"/"N"): print "No changes made." and exit 0

Step 4 — Remove marker block:
- Call `installer.BackupFile(rcFilePath)` — print: `  Backing up ~/.zshrc → ~/.zshrc.wt-backup`
- Call `installer.RemoveMarkerBlock(content)` to get new content
- Write new content to rc file with `os.WriteFile` (0644 permissions)
- If write fails: call `installer.RestoreBackup()`, print error, exit 1

Step 5 — Success:
```
Done! wt shell integration has been removed.

To complete uninstallation:
  1. Restart your terminal (or run: source ~/.zshrc)
  2. Run: npm uninstall -g @potato/wt
```
(For fish, adjust the source command to `source ~/.config/fish/config.fish`)

**Notes:**
- Use `fmt.Printf` / `fmt.Println` for all output (interactive command)
- Reuse the `~`-prefixed display path helper pattern from install.go
- The uninstall command only cleans up the rc file. It does NOT run `npm uninstall` — it prints the command for the user. Reason: the user is running `wt uninstall` which means the binary is still installed; removing the npm package would be self-destructive mid-execution.
- If the v1 lines were commented out by the installer (with `# [wt v2 migration]` prefix), the uninstall command does NOT uncomment them. The user can manually uncomment if they want to revert to v1. This is a deliberate choice — automatic uncommenting could be fragile.
