<objective>
Fix stdout leak in setup executor that garbles shell wrapper cd path.

Purpose: When `wt new` runs with `.wtconfig` actions (copy, symlink, run), progress messages
like "Copied foo" and "Symlinked bar" are printed to stdout via `fmt.Printf()`. The shell
wrapper captures ALL stdout as the cd target path, so these messages get prepended to the
path, causing `cd` to fail with "no such file or directory: Symlinked wt-bin\n/actual/path".
Similarly, `run.go` pipes run-action command output to stdout.

This plan also validates the existing WIP shell wrapper changes (already in working tree)
and ensures tests pass end-to-end.

Output: Clean stdout for shell wrapper coordination; all progress/debug output on stderr.
</objective>
